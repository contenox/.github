# .github

Organisation-wide defaults for [`contenox`](https://github.com/contenox).

| File | Applies to |
|---|---|
| `profile/README.md` | the text shown on <https://github.com/contenox> |
| `SECURITY.md` | every repository without its own — the vulnerability reporting policy |

GitHub falls back to the files here for any repository that does not define its
own, so a change here changes every repo at once.

The published, canonical security policy is
<https://contenox.com/legal/security>; `SECURITY.md` points at it rather than
restating it, so the two cannot drift.
